# Politique de confidentialité

**Dernière mise à jour : 20 août 2026**

StreamPulse est une application d'écoute et de diffusion audio réalisée dans le
cadre d'un projet d'études. Cette politique explique quelles données nous
traitons et ce que vous pouvez en faire. Elle est écrite pour être lue, pas pour
être survolée.

La version technique complète, avec le détail des durées et des bases légales,
se trouve dans [le dossier RGPD](rgpd.md).

## Ce que nous collectons

**Quand vous créez un compte** : votre adresse email, un nom d'utilisateur et
votre mot de passe. Le mot de passe n'est jamais conservé tel quel — nous n'en
gardons qu'une empreinte, qui ne permet pas de le retrouver.

**Quand vous utilisez l'application** : votre profil (pseudonyme, biographie,
avatar, préférences d'affichage et d'écoute), vos playlists, vos favoris, les
fichiers audio que vous téléversez, et les flux que vous diffusez si vous êtes
diffuseur.

**Automatiquement, à chaque requête** : la date, le chemin appelé, le code de
réponse, la durée, et le **préfixe réseau** de votre adresse IP. Nous ne
conservons pas votre adresse complète : les derniers chiffres sont remplacés par
zéro, ce qui suffit à repérer un incident sans identifier votre ligne.

## Ce que nous ne faisons pas

- Nous ne vendons ni ne partageons vos données.
- Nous n'utilisons aucun outil de mesure d'audience ni aucun traceur
  publicitaire.
- Nous n'analysons pas vos écoutes pour établir un profil.
- Nous ne transmettons rien à un tiers, à une exception : l'envoi des emails de
  réinitialisation de mot de passe passe par un service d'envoi.

## Combien de temps

| Donnée | Durée |
|---|---|
| Compte, profil, playlists, favoris, pistes, flux | Jusqu'à ce que vous supprimiez votre compte |
| Sessions de connexion | Jusqu'à la déconnexion ou l'expiration |
| Journaux techniques | 30 jours |
| Traces de diagnostic | 7 jours |
| Mesures de fonctionnement (sans identifiant) | 90 jours |

## Vos droits

**Consulter vos données.** L'application vous montre votre profil, vos flux, vos
playlists, vos pistes et vos favoris. Nous ne proposons pas encore de fichier
d'export récapitulatif.

**Corriger vos données.** L'écran de profil permet de modifier ce que vous avez
saisi.

**Supprimer votre compte.** Depuis les paramètres du compte. La suppression est
**définitive et immédiate** : votre compte, votre profil, vos playlists, vos
favoris, vos flux et vos fichiers audio sont effacés. Nous vous demandons votre
mot de passe avant de la faire, pour qu'un téléphone laissé sans surveillance ne
suffise pas.

Une seule chose survit : si vous avez été administrateur, les actes de
modération que vous avez effectués restent dans le journal d'audit, **sans votre
identité** — le fait est conservé, la personne est effacée.

**Récupérer vos données dans un format réutilisable.** Cette fonction n'existe
pas encore. Nous l'indiquons plutôt que de le laisser croire.

## Sécurité

Les échanges entre l'application et nos serveurs sont chiffrés. Vos jetons de
connexion sont rangés dans le magasin sécurisé de votre téléphone — Keychain sur
iOS, stockage chiffré sur Android. Les mots de passe et les jetons sont
conservés sous forme d'empreintes. Le détail des mesures figure dans le
[schéma de sécurité](securite.md).

## Nous contacter

Ce projet est réalisé par une équipe d'étudiants. Pour toute question relative à
vos données, ouvrez une issue sur le dépôt du projet.

## Modifications

Toute modification de cette politique est publiée avec le code, dans
l'historique du dépôt. La date en tête de document indique la dernière version.
